How to create a user account in Odoo:
    1. Go to Settings as Administrator
    2. Under Users, click on "-> Manage Users"
    3. Configure the user details such as Name, Email, and Access Rights
    4. Save the user account
    5. Go to the Employee's HR Information Tab
    6. Under the Related user Field Pick the user account that you just created
